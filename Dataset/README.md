# Dataset Information

## Smart Waste Classification Dataset

This project uses the Garbage Classification dataset available on Kaggle.

**Dataset Source:** [Garbage Classification Dataset – Kaggle](https://www.kaggle.com/datasets/sudipp/garbage-dataset-9-classes)

### Dataset Details

- Total Images: 20,029
- Number of Classes: 10
- Training Images: 14,020
- Validation Images: 3,004
- Testing Images: 3,005

### Waste Categories

1. Battery
2. Biological
3. Cardboard
4. Clothes
5. Glass
6. Metal
7. Paper
8. Plastic
9. Shoes
10. Trash

### Dataset Usage

The dataset was used for training, validation, and testing different Machine Learning and Deep Learning models for waste classification.

**Note:** The original dataset is hosted on Kaggle. Please download it from the source link above.
