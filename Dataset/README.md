# Smart Waste Classification

## Project Overview
Smart Waste Classification is a Deep Learning project that classifies waste images into different categories using Machine Learning and Deep Learning techniques.

## Dataset
The project uses the Garbage Classification dataset from Kaggle.

[Download Dataset](https://www.kaggle.com/datasets/sudipp/garbage-dataset-9-classes)

- Total Images: 20,029
- Number of Classes: 10
- Training Images: 14,020
- Validation Images: 3,004
- Testing Images: 3,005

## Waste Categories
1. Battery
2. Biological
3. Cardboard
4. Clothes
5. Glass
6. Metal
7. Paper
8. Plastic
9. Shoes
10. Trash

## Models Implemented
1. Random Forest
2. Support Vector Machine (SVM)
3. Artificial Neural Network (ANN)
4. Convolutional Neural Network (CNN)
5. CNN with Grid Search
6. Transformer

## Model Performance

| Model | Test Accuracy |
|---|---:|
| SVM | 97.37% |
| ANN | 96.11% |
| Random Forest | 94.98% |
| CNN | 78.70% |
| Grid Search CNN | 64.36% |
| Transformer | 56.21% |

The project compares traditional Machine Learning algorithms with Deep Learning architectures for waste image classification. Among the implemented models, SVM achieved the highest test accuracy of approximately 97.37%.
